## 一、 教学定位与核心目标

### 1. 本讲核心定位
> **让学生理解 Python 中常见数值运算（+、-、*、/、//、%）的真实意义，深刻区分三种除法运算（普通除法 /、整除 //、取余 %），并能够把生活中的简单数量关系翻译成 Python 表达式，让变量参与计算并输出结果。**

在第04讲中，学生已经掌握了程序状态的演进和“赋值号右边先计算，再把新结果赋给左边变量保存”的执行机制。第05讲顺理成章地回答核心问题：**“除了简单的 +1、+2，数据之间到底还可以怎样丰富地参与计算？”**。本讲不仅是算术运算符的建立，更是少儿编程中从“死记固定数据”走向“数量关系建模”的关键一步。

> **自然显性成果定位**：依据38讲课次地图上位标准，本讲**“自然显性成果：无，不强行包装”**。学生通过独立编写一个包含“变量定义 → 表达式计算 → 终端输出”的真实 Python 程序（`calc_05.py`）完成扎实的能力验证。

### 2. 核心素养与教学目标
1. **掌握六大基础算术符号**：熟练掌握 `+`、`-`、`*`（乘号）、`/`（普通除法）、`//`（整除）、`%`（求余），牢记键盘符号与数学符号的转换规则（不用 `×` 和 `÷`）；
2. **表达式认知构建**：理解“把数据、变量和运算符组合起来能算出结果的代码片段就是表达式”，树立“表达式会计算出一个新值”的思维模型；
3. **三种除法深刻辨析**：
   - `/`（普通除法）：计算精确商，结果始终为浮点数（如 `8 / 2 = 4.0`，`7 / 2 = 3.5`）；
   - `//`（整除）：在我们当前学习的非负整数分组问题中，表示“最多能完整分成多少组”（非负整数除法中商的整数部分，如 `7 // 2 = 3`）；
   - `%`（取余）：计算整除后剩余的零头（如 `7 % 2 = 1`）；
   - 理解“小除以大”规律（如 `3 // 5 = 0`，`3 % 5 = 3`）；
4. **变量参与表达式建模**：理解变量进入表达式时读取的是它在**当前时刻保存的值**，能将生活中的简单数量关系（如商品总价 `price * count`、找零 `pay - total`、物品装箱 `total // box` 与 `total % box`）翻译成 Python 表达式；
5. **真实环境独立编程验证**：在本地 Python IDE 中独立编写 `calc_05.py`，先在草稿纸上独立推演预测结果，再在真实终端运行核对验证。

## 二、 教学重难点与认知边界

### 1. 教学重点
- 六大基本算术运算符的书写与含义；
- `/`、`//`、`%` 三者面对同一组数据时的不同含义与对比；
- 让变量参与表达式计算（读取当前值）；
- 生活数量关系向 Python 表达式的翻译。

### 2. 教学难点
- 克服把乘法写成 `x` 或 `×`、把除法写成 `÷` 的习惯；
- 理解 `/` 输出总带小数点（`8 / 2` 得到 `4.0` 而非 `4`）；
- 彻底纠正把 `%` 当成“百分比”的直觉误区，树立“求余数”概念；
- 理解被除数小于除数时的特殊情况（`3 // 5 = 0`，`3 % 5 = 3`）。

### 3. 严格禁止超纲禁区（守卫底线）
- ❌ **严禁提前教授 `**` 幂运算**（留给第06讲）；
- ❌ **严禁展开复杂运算优先级体系与复杂带括号混合运算**（留给第06讲，本讲只做单步或极为明确的顺序运算）；
- ❌ **严禁提前教授 `+=`、`-=`、`*=`、`/=` 等复合赋值符号**；
- ❌ **严禁提前引入 `input()`**（留给第08讲，本讲必须使用固定变量）；
- ❌ **严禁展开负数向下取整的底层复杂细节**（本讲实例严格限定在非负整数范围）；
- ❌ **严禁提前把 `%` 展开讲成奇偶判断算法、因数质数、数位拆解**（后续课次会有专用课次回收展开）；
- ❌ **严禁提前引入 `if/else` 条件分支、`for/while` 循环、函数、列表**。

## 四、 课堂教师话术与分镜教学指引

### 1. 导入话术（第02~03幕）
> “同学们，上一节课我们攻克了一个大难关——`x = x + 1`！大家已经知道，Python 看到这一行，会先看等号右边，把 `x + 1` 算出来，再放回左边的盒子里。  
> 可是如果编程只能算‘加1’，计算机可就太弱了！去超市结账要算总价、分披萨要算每个人得几份、做游戏要算生命值扣减……在 Python 里，数据到底可以怎样被我们‘加工’呢？今天我们就来学习 Python 的六大算术法宝，一起用代码算清楚身边的数学关系！”

### 2. 突破难点：烘焙坊打包情境与除法三兄弟话术（第05~07幕）
> “大家来看屏幕！小熊烘焙坊刚刚烤出 17 块香喷喷的曲奇饼干，每 5 块装满一个礼品盒。
> 打包机飞速运转，装满了 3 个整盒，贴上封条运上货车了！
> 这时候，案板上还孤零零剩下了 2 块散装饼干！
> 老板发问了：‘装完整盒后，桌上剩下的零头有几块？’
> 小朋友们在小学数学本上会写：`17 ÷ 5 = 3 …… 2`，商是 3，余数是 2。
> 可是请大家低头看看电脑键盘——键盘上有‘……’这个除法余数键吗？一个也没有！
> Python 怎么帮我们把那‘剩下的 2 块零头’单独抓出来？
> 隆重请出我们的除法家族三兄弟：
> - 大哥叫做 **普通除法 `/`**：像激光手术刀，切得无比精确，哪怕除得尽也带小数，`17 / 5 = 3.4`；
> - 二哥叫做 **整除 `//`**：像快递装箱员，在非负整数分组中专门算‘最多能完整装几整盒’，`17 // 5 = 3`，整盒运走！
> - 三哥叫做 **取余 `%`**：像破案神探，专门盯着桌上散落装不下的零头！平时在商场看到 50% OFF 是打折，在 Python 算术里它专抓余数，`17 % 5 = 2`！
> 记住口诀：**// 算整盒，% 抓零头！两兄弟分工合作，所有数据安排得明明白白！**”

### 3. 突破难点：小除以大（第08幕）
> “如果桌上只有 3 颗糖，现在老师要求你们‘每 5 颗装一袋’，你们能装出几整袋？  
> 是不是一袋都装不满？所以商是 0，也就是 `3 // 5 = 0`！  
> 那装完 0 袋以后，桌上还剩下几颗糖没装进去？那 3 颗不是全都在吗！所以余数是 3，也就是 `3 % 5 = 3`！  
> 记住了：**小家伙除以大个子，整袋是 0，余数就是小家伙自己！**”

### 4. 突破思维跃迁：文具店收银危机与变量建模话术（第10幕）
> “同学们，快看第10幕！放学铃声一响，文具店收银台前挤满了排队的同学：
> - 顾客小明买 4 支 12 元钢笔，程序员在代码里写 `total = 12 * 4`，算出 48 元；
> - 刚算完，顾客小红跑过来：‘我要买 6 本 8 元草稿本！’程序员慌了，赶紧停下程序，把 12 改成 8，把 4 改成 6，重新运行；
> - 这时顾客小刚又喊：‘我买 10 盒 15 元彩笔！’程序员急出一头大汗，后面的队伍已经排到校门口了！😱
> 老板气急败坏：‘每来一个顾客你都要重新改一遍代码，程序难道是一次性筷子吗？！’
> 大家想一想，把数字写死在算式里（硬编码），程序只能算一单，根本无法应对真实世界！
> 聪明的程序员怎么做？用**变量建模**！
> 现实中商品的单价在变、数量在变，但**核心数学关系永远不变**：`总价 = 单价 × 数量`！
> 我们把单价叫 `price`，数量叫 `count`，写成通用表达式：
> `total = price * count`
> 现在，大家看右边的屏幕——来买草稿本？换入 `price = 8; count = 6`；来买彩笔？换入 `price = 15; count = 10`！
> 我们的收银公式 `total = price * count` **一字不用改**，秒出正确总价！
> 这就是今天最重要的思维飞跃：**数字是写死的一性数据，变量是通用的计算模具！让变量参与表达式，程序就拥有了服务千家万户的自动化能力！**”

## 六、 课后分层练习与迁移变式库（真题能力对齐，无标签化）

依据官方真题考查重点内化设计，严格遵循当前知识边界，不使用任何外部标签，供课后练习与课堂小测使用：

### 题型1：基础运算符识别与符号转换
* **题目**：在 Python 中，表达式 `8 / 2` 与 `6 * 7` 的计算结果分别是什么类型与数值？
* **参考答案**：`8 / 2` 的结果是浮点数 `4.0`（普通除法始终输出带小数的结果）；`6 * 7` 的结果是整数 `42`。

### 题型2：除法三兄弟 `/`、`//`、`%` 综合辨析
* **题目**：已知 `total = 20`，`group = 6`。请推演并写出以下三行代码的屏幕输出结果：
  ```python
  print(total / group)
  print(total // group)
  print(total % group)
  ```
* **参考答案**：
  - `print(total / group)` 输出 `3.3333333333333335`（普通除法结果）；
  - `print(total // group)` 输出 `3`（非负整数除法中最多完整分 3 组）；
  - `print(total % group)` 输出 `2`（分完 3 组后剩下的余数零头）。

### 题型3：变量表达式与当前值代入
* **题目**：阅读下列代码，写出变量 `area` 和 `perimeter` 的最终输出值：
  ```python
  width = 8
  height = 5
  area = width * height
  perimeter = width + width + height + height
  print(area)
  print(perimeter)
  ```
* **参考答案**：`area` 输出 `40`；`perimeter` 输出 `26`。

### 题型4：简单生活数量关系翻译
* **题目**：电影院爆米花每桶 `price = 15` 元，饮料每杯 `drink = 8` 元。小红买了 2 桶爆米花和 1 杯饮料，付了 `pay = 50` 元。请写出计算总消费 `total` 和应找零钱 `change` 的 Python 表达式。
* **参考答案**：
  ```python
  popcorn_cost = 15 * 2
  total = popcorn_cost + 8
  change = 50 - total
  ```

### 题型5：深度迁移变式（时间换算模型）
* **题目**：一段音频的总时长为 `total_seconds = 135` 秒，每 60 秒为 1 分钟。请用变量 `minutes` 表示整分钟数，用变量 `seconds` 表示剩余的秒数，写出计算表达式并得出各自的数值。
* **参考答案**：
  ```python
  total_seconds = 135
  minutes = total_seconds // 60   # 135 // 60 得到 2（最多满 2 分钟）
  seconds = total_seconds % 60    # 135 % 60 得到 15（还剩下 15 秒）
  ```
  最终为：2 分 15 秒。
