核心概念

把数据与运算符连起来：表达式（Expression）💡

观察这个经典结构：
8 * 3 ➔ 算出结果 ➔ 24
🧱 什么是表达式？
把数据（数字或变量）与运算符（加减乘除等）组合在一起，能够产生一个计算结果的代码片段，就叫做表达式！
🎯 表达式的核心特征
每一个合法的算术表达式，最终都会求值（Evaluate）计算出一个具体的结果，这个结果可以被 print() 打印，也可以赋给变量保存！

核心辨析

一个斜杠 vs 两个斜杠：/ 与 // 的关键区别 🔍

🍰 一个斜杠 /：普通除法（激光手术刀）
print(7 / 2)  # 输出 3.5
print(8 / 2)  # 输出 4.0
就像分蛋糕：每一块都切得无比精确！即使能整除，结果也始终是一个带小数点的浮点数！
📦 两个斜杠 //：整除（快递装箱员）
print(7 // 2) # 输出 3
print(8 // 2) # 输出 4
就像打包分装：在我们当前学习的非负整数分组问题中，// 表示最多能完整分成多少组（即非负整数除法中商的整数部分）！
🌟 黄金口诀：一个斜杠切出精确小数，两个斜杠算出最多能分几整组！
余数奥秘

别被外表骗了！% 在 Python 里是“取余数” 🎁

🍪 生活情境：17 块饼干，每 5 块装一盒
• 能够装满几整盒？➔ 3 盒（这是商！）
• 装完 3 盒后，盒子里装不下、还剩下几块？➔ 2 块（这是余数！）
在数学里我们写：17 ÷ 5 = 3 …… 2
在 Python 里我们用两个符号分别算出来！
cookies.py
1print(17 // 5)  # 整除：装满 3 盒
2print(17 % 5)   # 取余：还剩 2 块
>_ 终端输出：
3
2
💡 核心辨析：% 在算术表达式中绝不是打折或百分比，它是专门帮我们找余数的“余数探长”！
三法同堂

同一组数据大比拼：17 与 5 的三种答案 📊

① 普通除法 /
17 / 5 ➔ 3.4
回答：每个人精确分多少？答案是 3.4 份（带小数）。
② 整除 //
17 // 5 ➔ 3
回答：最多能完整分成几整组？答案是 3 组（非负整数除法中商的整数部分）。
③ 取余 %
17 % 5 ➔ 2
回答：分完后还剩下几个零头？答案是剩下的 2 个。
🧐 小思考：如果刚好整除呢？例如 15 // 5 ➔ 3，而 15 % 5 ➔ 0（余数为 0 表示刚好分完，没有零头）！
特殊场景

逆向思维：只有 3 颗糖，每 5 颗装一盒？🍬

🤔 很多同学在这里容易卡壳：
被除数比除数还小，怎么除？
• 问：手里只有 3 颗糖，要求装满 5 颗才能装一盒，你能装几盒？
➔ 连一盒都凑不齐！所以整除只能装 0 盒！
• 问：装完 0 盒后，手里还剩下几颗糖？
➔ 那 3 颗糖一颗都没动，原封不动剩下 3 颗！
small_divide.py
1print(3 // 5)  # 能装满 0 盒
2print(3 % 5)   # 还剩下 3 颗
>_ 终端输出：
0
3
🌟 规律总结：当被除数小于除数时，整除结果必然是 0，余数就是它自己！

变量建模

从数字到变量：让程序拥有通用计算能力 🏷️

❌ 数字直接写死（不够灵活）
total = 12 * 4
print(total)
如果商品单价变了、购买数量变了，必须重新修改代码里的数字！
✅ 变量通用表达式（专业写法）
price = 12
count = 4
total = price * count
print(total)
无论数量和价格怎么变，price * count 这个关系永远成立！
🌟 核心认知：变量参与表达式时，Python 会自动读取该变量在当前时刻保存的数值代入计算！
关系建模

小小数学家：把生活数量关系翻译成代码 📝

🛒 生活情境：文具店买铅笔
铅笔单价 price = 3 元，小明买了 count = 5 支，小明付给老板 pay = 20 元。请计算应付总价和应找零钱！
shop.py
1price = 3
2count = 5
3pay = 20
4total = price * count  # 算出 15
5change = pay - total    # 算出 5
6print(total)
7print(change)
🎯 数量关系翻译三步法：
① 找出已知数据：单价 price、数量 count、付款 pay
② 确定计算关系：
• 总价 = 单价 × 数量 ➔ price * count
• 找零 = 付款 - 总价 ➔ pay - total
③ 赋值并输出：把计算出的结果交给新变量并打印！
易错辨析

侦探眼：排查算术运算四大易混陷阱 🔍

⚠️ 陷阱 1：把乘法写成字母 x 或 ×
a = 3 x 4 会直接导致语法报错（SyntaxError）！计算机中的乘号只能是星号 *！
⚠️ 陷阱 2：以为 8 / 2 得到整数 4
print(8 / 2) 输出的是 4.0！普通除法只要一出手，结果必然带小数！想要整数 4 请用 8 // 2！
⚠️ 陷阱 3：以为 % 是百分比打折
在 Python 中 100 % 10 不是打十折，而是算余数！100 % 10 = 0！
⚠️ 陷阱 4：看见 a = a * 2 以为是等式
永远牢记右算左赋：先算出右边 a * 2 的结果，再更新覆盖给左边的 a！
