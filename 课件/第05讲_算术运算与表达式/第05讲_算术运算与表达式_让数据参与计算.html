核心概念

把数据与运算符连起来：表达式（Expression）💡

观察这个经典结构：
8 * 3 ➔ 算出结果 ➔ 24
🧱 什么是表达式？
把数据（数字或变量）与运算符（加减乘除等）组合在一起，能够产生一个计算结果的代码片段，就叫做表达式！
🎯 表达式的核心特征
每一个合法的算术表达式，最终都会求值（Evaluate）计算出一个具体的结果，这个结果可以被 print() 打印，也可以赋给变量保存！

核心辨析

一个斜杠 vs 两个斜杠：/ 与 // 的关键区别 🔍

🍰 一个斜杠 /：普通除法（激光手术刀）
print(7 / 2)  # 输出 3.5
print(8 / 2)  # 输出 4.0
就像分蛋糕：每一块都切得无比精确！即使能整除，结果也始终是一个带小数点的浮点数！
📦 两个斜杠 //：整除（快递装箱员）
print(7 // 2) # 输出 3
print(8 // 2) # 输出 4
就像打包分装：在我们当前学习的非负整数分组问题中，// 表示最多能完整分成多少组（即非负整数除法中商的整数部分）！
🌟 黄金口诀：一个斜杠切出精确小数，两个斜杠算出最多能分几整组！
情境探索 · 余数奥秘

🍪 烘焙工坊打包记：装完整盒后，桌上剩下的零头怎么办？🎁

🍪 生活情境：小熊烘焙坊烤好了 17 块香脆曲奇，每 5 块装一盒！
生活悬念
• 工厂打包机装满了 3 个完整礼盒（15 块饼干），贴好封条运上货车。
• 可是案板上还孤零零剩下了 2 块散装饼干！拿大盒子装不满，怎么办？
🤔 思维冲突：数学作业本上写 17 ÷ 5 = 3 …… 2，但电脑键盘上根本没有“……”这个符号！Python 怎么帮我们单独算出那“剩下的 2 块零头”？
📦 饼干打包图解：整盒 vs 零头
① 能够装满几整盒？（商） 17 // 5 ➔ 3 盒
🎁 盒1 (5块) 🎁 盒2 (5块) 🎁 盒3 (5块)
② 装不下、剩下的零头？（余数） 17 % 5 ➔ 2 块
🍪 🍪 孤单散装 2 块（装不满一整盒）
⚠️ 辟谣专栏：平时在商场看到 50% OFF 是打折百分比，而在 Python 算术里，% 是专抓余数的“零头探长”！
cookies.py
1# 17块饼干，每5块装一盒
2print(17 // 5)  # 整除：装满 3 盒（商）
3print(17 % 5)   # 取余：剩下 2 块（余数）
>_ 终端输出：
3 (整盒运走)
2 (剩下零头)
💡 黄金搭档口诀：// 算整盒（商），% 抓零头（余数）！两兄弟合力分工，所有数据安排得明明白白！
三法同堂

同一组数据大比拼：17 与 5 的三种答案 📊

① 普通除法 /
17 / 5 ➔ 3.4
回答：每个人精确分多少？答案是 3.4 份（带小数）。
② 整除 //
17 // 5 ➔ 3
回答：最多能完整分成几整组？答案是 3 组（非负整数除法中商的整数部分）。
③ 取余 %
17 % 5 ➔ 2
回答：分完后还剩下几个零头？答案是剩下的 2 个。
🧐 小思考：如果刚好整除呢？例如 15 // 5 ➔ 3，而 15 % 5 ➔ 0（余数为 0 表示刚好分完，没有零头）！
特殊场景

逆向思维：只有 3 颗糖，每 5 颗装一盒？🍬

🤔 很多同学在这里容易卡壳：
被除数比除数还小，怎么除？
• 问：手里只有 3 颗糖，要求装满 5 颗才能装一盒，你能装几盒？
➔ 连一盒都凑不齐！所以整除只能装 0 盒！
• 问：装完 0 盒后，手里还剩下几颗糖？
➔ 那 3 颗糖一颗都没动，原封不动剩下 3 颗！
small_divide.py
1print(3 // 5)  # 能装满 0 盒
2print(3 % 5)   # 还剩下 3 颗
>_ 终端输出：
0
3
🌟 规律总结：在我们当前学习的非负整数分组问题中，当被除数小于除数时，整除结果是 0，余数就是被除数本身！

💻 代码实战推演：除法三兄弟在程序中如何分工？🔍

📌 同一组数据 19 和 4，三条语句输出了三个截然不同的答案！
🍰 ① 普通除法 /
回答：如果每一份都分得丝毫不差，每个人精确分得多少？
➔ 答案是 4.75 份（始终带小数）。
📦 ② 整除 //
回答：按 4 个一组打包，最多能完整装满几整盒？
➔ 答案是 4 盒（非负整数中商的整数部分）。
🍪 ③ 取余 %
回答：装满 4 盒之后，桌上还剩下几个单装不下的零头？
➔ 答案是剩下的 3 个零头。
💡 核心法则：面对同一对数据，三种除法分别回答了三种完全不同的实际生活问题，各司其职、不可替代！

易错辨析

侦探眼：排查算术运算四大易混陷阱 🔍

⚠️ 陷阱 1：把乘法写成字母 x 或 ×
a = 3 x 4 会直接导致语法报错（SyntaxError）！计算机中的乘号只能是星号 *！
⚠️ 陷阱 2：以为 8 / 2 得到整数 4
print(8 / 2) 输出的是 4.0！普通除法只要一出手，结果必然带小数！想要整数 4 请用 8 // 2！
⚠️ 陷阱 3：以为 % 是百分比打折
在 Python 中 100 % 10 不是打十折，而是算余数！100 % 10 = 0！
⚠️ 陷阱 4：看见 a = a * 2 以为是等式
永远牢记右算左赋：先算出右边 a * 2 的结果，再更新覆盖给左边的 a！
