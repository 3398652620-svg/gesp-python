核心认知 01

计算机只听毫无歧义的明确指令！💡

什么是“指令”？
指令 (Instruction)，就是告诉计算机去执行的一个毫无歧义的最小动作。
❌ 模糊人话：“把作业收一下”、“稍微等一下”、“走快点”
✅ 明确指令：“收集 40 本作业本”、“等待 5 秒钟”、“前进 10 米”
🧠 ➔ 💻
人会替别人“脑补猜心思”；
但计算机只按明确规则执行！
没有清晰指令，超级计算机也只是一堆废铁。

概念建构 12~22min

回头解释：刚才为什么能运行？📜

1. 什么是“程序”？
刚才的两行代码：
- 每一行，是一条独立的明确指令；
- 把多条指令按照规则排列组合在一起，就是程序 (Program)！
📦 程序 = 按规则排列的一组指令
2. Python 是什么？
- 人类说的是自然语言（汉语、英语）；
- 电脑底层的芯片只认电信号；
- Python 就是人类与计算机之间的“超级翻译官 / 沟通桥梁”！
🐍 人类想法 ➔ Python 代码 ➔ 计算机执行

工作法则

程序员的“黄金四步工作法” 🔁

1. 写指令 (Write)：想清楚规则，写出明确代码。
2. 点运行 (Run)：让计算机从上到下一行行执行。
3. 观察结果 (Observe)：仔细核对屏幕输出与预期是否一致。
4. 修改再试 (Modify)：像小侦探一样微调代码，再跑一次！
🕵️ 侦探小技巧：漏了双引号怎么办？
如果不小心写成 print("你好)，电脑会亮起红灯报警。
别慌！电脑没有坏！
双引号就像两扇门，有开门就必须有关门。补齐右侧的双引号 "，再点运行，就能立即恢复！
✨ 调试 (Debug) 就是小侦探找线索的过程！

小程序员的思考总结 🧠

1. 计算机会不会猜你的心里想法？
👉 绝不替人猜！ 必须给予精准、毫无歧义的明确规则与指令。

👉 自上而下，一行一行，绝不跳步！ 计算机严格按照你写下的代码顺序执行，不替你自作聪明。
3. 如果程序跑出的结果不对，第一步该怎么办？
👉 电脑没有坏！ 像小侦探一样回到代码检查内容与顺序，修改后再运行验证！
