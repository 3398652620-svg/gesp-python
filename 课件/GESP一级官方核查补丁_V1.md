# 四、补丁 3：第03讲明确覆盖标识符、关键字与基础命名规则

第03讲仍保持：

> **变量与赋值：让程序记住数据**

课次位置与核心认知不变。

制作《第03讲单讲课研规格》时，必须纳入以下基础内容：

- 合法变量名基本规则；
- 字母、数字、下划线；
- 变量名不能以数字开头；
- Python大小写敏感；
- Python关键字不能作为普通变量名；
- 有意义的变量命名；
- 常量命名约定可轻量认识，不做复杂规范专题。

重点仍然是：

> **变量用来保存程序当前需要记住的数据。**

命名规则是变量课的必要组成部分，但不能反客为主变成“标识符考试课”。

# 五、补丁 4：第11讲确保覆盖一级常见输出阅读形式

第11讲仍保持：

> **输出组织与顺序程序综合**

不改课次定位。

制作详细课研规格时，除完整顺序程序外，应确保学生能够理解一级常见的基础输出控制，例如：

```python
print(..., end="")
```

如教学负荷合适，可同时轻量认识常见多项输出形式。

## 约束

不把第11讲改造成：

> print高级参数大全

本讲主线仍然是：

> **输入 → 转换 → 计算 → 清晰输出 → 完整顺序程序**

`end` 等内容只作为必要的阅读与输出能力补充。
