## 一、 教学定位与核心目标

### 1. 本讲核心定位
> **让学生掌握 `print()` 基础输出工具，理解文字需要成对引号表示为字符串，初步区分数值与字符串，并在多行代码中巩固顺序执行模型（预测 ➔ 运行验证），独立编写固定信息卡程序。**

本讲**不是**完整的数据类型分类课，也**不是**多参数 print 语法课，而是建立程序向屏幕表达文字与数字的核心基本功。

### 2. 核心素养与教学目标
1. **指令工具认识**：认识 `print()` 是 Python 中专门用来向屏幕输出/显示信息的基本指令；
2. **字符串与引号**：理解直接写出文字时必须用成对引号包起来（字符串），建立“带引号是文字，不带引号会报错”的边界；
3. **符号规范**：掌握单双引号成对法则，严格区分代码语法符号（英文半角）与引号内文字符号；
4. **数据形式初步辨析**：认识数值数据（直接写数字）与字符串数据（成对引号包裹），理解 `10` 与 `"10"` 看起来相似但数据形式不同（“显示出来一样，不代表程序里的数据一样”）；
5. **顺序执行巩固**：通过多行 `print()` 顺序预测与调换顺序变式，固化“代码从上到下一行行执行”的思维模型；
6. **真实实战与排错**：在本地 IDE 中独立编写并保存包含文字与数字的《我的第一张 Python 信息卡》（`my_card_02.py`），并具备基础符号排错能力（识别中文括号）。

## 二、 教学重难点与认知边界

### 1. 教学重点
- `print()` 指令语法结构（括号、成对引号）；
- 字符串概念与引号的作用；
- 数值与字符串的初步区别；
- 多行代码顺序执行的预测与验证。

### 2. 教学难点
- `print("hello")` 与 `print(hello)` 的错误原因；
- `10` 与 `"10"` 的本质区别（数值形式 vs 文字形式）；
- 代码调换顺序后输出随之改变的必然性。

### 3. 严格禁止超纲禁区（守卫底线）
- ❌ 严禁正式系统教授 `int` / `float` / `str` 术语分类与强制背诵（留给后续课次逐步精确）；
- ❌ 严禁将多内容逗号输出 `print("姓名：", 10)` 作为核心考核要求；
- ❌ 严禁提前引入变量、赋值、`input()`、类型转换 `int()` / `str()`、`type()`；
- ❌ 严禁提前展开 `print(hello)` 的变量查找机制与 `NameError` 术语（留给第03讲）；
- ❌ 严禁引入参数、函数、转义字符、`sep`、`end`。
