## 一、教学定位与核心目标

### 1. 本讲核心定位

> **让学生理解：变量是程序给数据起的名字；`=` 是"把右边的值放进去"；名字里装的东西可以换，换完之后程序记住的是最新的那个。**

本讲是整套课程第一次真正进入「程序状态」的一课。

> **本讲最需要小心的地方**：几乎每个孩子都会问"老师，那我直接改上面那行不就行了？"——这个问题的应对方式，决定了孩子以后还敢不敢提问，也决定了他能不能真正接受"变量"这件事。

### 2. 核心素养与教学目标

1. **变量本质**：理解变量是程序给数据起的名字，用这个名字可以反复取用同一份数据；
2. **赋值逻辑**：掌握 `名字 = 值` 的写法，建立"**先看右边是什么，再把它放进左边的名字**"的阅读方向；
3. **辨析边界**：清晰区分 `print(name)`（取名字里装的值）与 `print("name")`（输出字符串本身）；
4. **重新赋值（本讲重点）**：理解同一个名字里装的东西可以更换；程序在某个位置读到的，是到那个位置为止最后一次放进去的值；
5. **多类型保存**：理解变量可以装文字（要引号）和数字（不要引号），延续第01讲的"数字 vs 文字"；
6. **命名基本规则**：名字要有意义、不能数字开头、大小写敏感；其余规则轻量带过；
7. **真实实战**：把第01讲写死的信息卡改写成变量版，亲眼看到"数据集中、改一处全生效"。

## 二、教学重难点与认知边界

### 1. 教学重点
- 变量 = 数据的名字，赋值方向"先看右边"；
- `name` vs `"name"` 的辨析；
- **重新赋值：同一个名字前后取值不同**；
- **"这个名字现在装着什么？"这个追问句式**。

### 2. 教学难点
- 理解 `=` 是动作，不是数学等号；
- **理解变量会变，且理解"为什么不能提前写好"这件事现在还没到能讲的时候**；
- 大小写敏感（`age` 与 `Age` 是两个名字）。

### 3. 严格禁止超纲禁区（守卫底线）
- ❌ 严禁试图"论证"为什么必须能变（**本讲最大陷阱**）；
- ❌ 严禁正式教授 `int` / `float` / `str` 术语背诵；
- ❌ 严禁把多内容逗号输出 `print("姓名：", name)` 作为核心要求（仅卡片示例中出现）；
- ❌ 严禁提前正式教学 `x = x + 1`（仅作课尾悬念，不解释、不练习）；
- ❌ 严禁引入 `input()`、类型转换、`+=`、变量交换、Trace Table；
- ❌ 严禁把变量永远讲成静态"盒子"；
- ❌ 严禁把命名规则做成半节背诵课。

## 四、课堂教师话术与分镜教学指引

### 1. 导入话术（第01~02幕）

> "同学们，上节课我们每个人都做了一张信息卡，还记得长什么样吗？"
>
> ```python
> print("==========")
> print("我的信息卡")
> print("姓名：小明")
> print("爱好：机器人")
> print(10)
> print("==========")
> ```
>
> "现在老师问一个问题——**如果今天来的是小红，你想把这张卡改成小红的，你要改几个地方？**"
>
> （让孩子数一数，多数会答"一到两个地方"）
>
> "改一处还行。那要是这张卡你要做**十张**呢？小明的、小红的、小刚的……
>
> 每一次都要把'小明'改一遍，**改漏一个就出错**。这多麻烦啊。
>
> 那……**有没有办法，让'小明'只写一次？**"
>
> **（停一下，让孩子想一想。不要急着给答案——这一步是引出"变量"的关键。）**
>
> "有！今天我们就学这个办法——把数据**只在一个地方写下**，以后要用，直接叫它的名字去取。
>
> 这个'名字'，就叫——**变量**。"

### 2. 变量是什么 & 变量与赋值话术（第03~05幕）

**【第03幕：先正面讲清"变量是什么、能干嘛"】**

> "上节课我们做了一张信息卡。今天要学一个新东西，它叫——**变量**。
>
> 这个词听起来有点吓人，其实特别简单：**变量，就是给数据起的一个名字。**
>
> 什么意思？上节课我们的数据是这样写的："
>
> ```python
> print("姓名：小明")
> print("爱好：机器人")
> print(10)
> ```
>
> "数据都'写死'在里面。今天我们要换个写法——给每个数据起个名字："
>
> ```python
> name = "小明"
> hobby = "机器人"
> age = 10
> ```
>
> "以后要用，**叫名字**就行。"
>
> **【生活例子 · 用"电话手表里的妈妈"建立直觉】★**
>
> "停一下，老师先问你们一件生活里的事——**谁有电话手表？**"
>
> （大部分孩子会举手）
>
> "手表里是不是存了'妈妈'？按一下名字就能打给妈妈。那老师问你——**你记得妈妈的号码吗？**"
>
> （孩子多半摇头）
>
> "对，你根本不用记。那一长串号码，**只存了一次**，就放在'妈妈'这个名字下面。你想打的时候，**叫名字**就行。
>
> 而且——要是妈妈换号码了呢？你也**只要改手表里这一处**，以后按'妈妈'，打的就是新号码。"
>
> "程序里的**变量**，就是这个道理，一模一样。"
>
> （屏幕对照：📱 电话手表里 `138****8888 → 妈妈`　｜　🐍 程序里 `"小明" → name`）
>
> **【教学提示】** 不要用"盒子""储物柜"来打比方。盒子是**固定容器**，会让孩子形成"变量是个装东西的格子"的心智模型，下一讲 `x = x + 1` 时要费很大力气打破。用"名字/通讯录"则天然支持"名字指向的东西可以换"——**为下一讲留好后路**。
>
> "那变量到底能帮我们干嘛？两件事——"
>
> **【板书 · 两条】**
>
> > ① **存一次，到处用**：数据只写一遍。以后要用，叫名字就行，不用每次都重写一遍。
> > ② **改一处，全生效**：刚才那个麻烦，这就解决了——想把"小明"改成"小红"？只改一个地方，下面用到的地方全跟着变。
>
> "第②条到底有多爽，等下动手做的时候你会亲眼看到。先记住这两句话——**存一次，到处用；改一处，全生效。**"

**【第04幕：怎么写一行变量】**

> "现在来看，怎么写一行变量。看这行代码："
>
> ```python
> name = "小明"
> ```
>
> "它分成三块。第一块，`name`，这是我们**给数据起的名字**。第二块，这个等号。第三块，`"小明"`，这是**真正要保存的数据**。
>
> 那这个等号是什么意思呢？"
>
> **（这里要停一下，等孩子回答）**
>
> "很多同学会说'等于'。但是老师告诉你们——**在这里，它不是'等于'的意思。**
>
> 它是一个**动作**。什么意思呢？就是：**把右边的这个东西，放进左边的名字里。**
>
> 所以我们读这行代码，不读'name 等于 小明'，我们读——
>
> **'把小明放进去，放到的名字叫 name。'**"
>
> （板书或屏幕强调，重复全班齐读一次）
>
> "记住这个顺序：**先看右边是什么，再把它放进去。** 这个顺序特别重要，下节课还要用到。"
>
> 【互动】
>
> "那我考考你们——"
>
> ```python
> score = 90
> ```
>
> "这行代码怎么读？谁能用刚才的句式说出来？"
>
> （期望答案："把 90 放进去，放到的名字叫 score"）
>
> **【必讲一句 · 变量要先定义，才能用】★**
>
> "最后，这一整行，我们给它一个说法——它叫**"定义变量"**。
>
> 请大家记住一句话：**变量要先定义，才能用。**
>
> 什么意思呢？就是：你得**先写出 `name = "小明"` 这一行**，后面才能 `print(name)`。
>
> 如果一行都没定义过，就直接写 `print(name)` —— 程序会说："**我不认识这个名字。**"
>
> （这一条，第10幕还会用错误案例再强化一次。**必须讲，不能默认孩子会自己悟出来。**）"

### 3. 引号规则话术（第06~07幕）★

> "先看这三行："
>
> ```python
> name = "小明"
> print(name)
> print("name")
> ```
>
> "第 2 行和第 3 行，**只差一个引号**。先猜一猜——它们打印出来一样吗？"
>
> （让孩子猜，多数会以为一样）
>
> "我们来跑一下。第 2 行出来的是**小明**，第 3 行出来的是 **name 这四个字母**。为什么会这样？我们一行一行看。"
>
> **（看第 2 行）**
>
> "`print(name)`。注意——`name` **没有穿引号**。
>
> 上节课我们说过一句话：**只有文字才穿引号外套**。那没穿引号的 `name`，它就不是文字。它是什么？——它是个**变量名**。
>
> 程序看到变量名，就会**去找这个名字**，把里面装的'小明'拿出来。所以打印出 **小明**。"
>
> **（看第 3 行）**
>
> "`print("name")`。这次 `name` **穿了引号**。
>
> 还记得上节课的规矩吗——**穿了引号，它就是一段文字**。而这段文字的内容，恰恰就是 n-a-m-e 这四个字母。
>
> 文字会怎么样？——**原样显示**。所以屏幕上打出 **name**。"
>
> "所以两行的区别，就在**有没有引号**：
>
> - **没引号** → 是**变量名**，程序去把里面的值取出来；
> - **有引号** → 是**文字**，原样显示。"
>
> 【互动：小侦探】（第07幕）
>
> "既然知道了这个规矩，我们来做一回小侦探。程序里已经写好了第一行——"
>
> ```python
> name = "小明"
> ```
>
> "下面这四行，如果接在它后面，**哪些能跑出'小明'？**"
>
> - `print(name)` ✅ 没引号 → 变量名，取出里面的"小明"
> - `print("name")` ❌ 有引号 → 文字，原样显示 name 四个字母
> - `print("小明")` ✅ 有引号 → 文字，原样显示"小明"
> - `print(nam)` ❌ 变量名拼错了，程序不认识 nam
>
> 教师提示：点选时**一定要先问"这行有没有引号"**，让孩子用刚学的规矩判断，而不是凭眼睛看像不像。

### 4. 多类型保存话术（第08幕）

> "变量里，只能装文字吗？"
>
> ```python
> name = "小明"
> age = 10
> height = 1.52
> ```
>
> "看这三个：`name` 装的是文字，**要穿引号外套**；`age` 装的是 10，**不用引号**；`height` 装的是 1.52，小数点数字，**也不用引号**。
>
> 所以答案是——**不只能装文字**。文字、整数、小数，都能装进变量里。
>
> 而且**取出来的方式完全一样**，写出变量名就行：`print(name)`、`print(age)`、`print(height)`。
>
> 只有一条规矩没变，跟上节课一样——**文字要引号，数字不用引号。**
>
> （点一句）注意：**引号是给"数据"穿的，跟变量名没关系。**"

### 5. 命名规则话术（第09~11幕）

> "现在我们知道了，名字是随便起的吗？老师试试起个名字——"
>
> ```python
> 2age = 10
> ```
>
> "运行一下……报错了！
>
> 为什么？因为 Python 规定：**名字不能以数字开头。** 你想想，如果名字能以数字开头，那 `2age` 和 `2 age` 电脑就分不清了。"
>
> "还有一条，特别有意思——"
>
> ```python
> age = 10
> Age = 15
> ```
>
> "这两个名字，是**同一个**还是**两个不同的**？
>
> （让孩子猜）
>
> **是两个不同的！** 在 Python 眼里，大写 A 和小写 a 完全是两回事。所以 `age` 是 `age`，`Age` 是 `Age`，它们各自装各自的东西。
>
> 如果你写了 `age = 10`，然后 `print(Age)`，程序会说：'我不认识 Age 是谁'。"
>
> "最后一个，也是最重要的——**名字要让人看得懂。**"
>
> ```python
> a = "小明"
> name = "小明"
> ```
>
> "这两个都对，但哪个更好？
>
> （孩子会答 name）
>
> "对。因为程序是要给人看的。三个月以后你自己回头看，`name` 一眼就懂，`a` 就完全不知道是什么了。
>
> 目标是——**看到名字，就知道里面装的是什么。**"
>
> "最后把'能用不能用'的规矩收一收，其实就三条——"
>
> **【板书 · 三条规矩】**
>
> > ① 只能用 **字母 / 数字 / 下划线**
> > ② **不能以数字开头**
> > ③ **中间不能断开**（不能有空格）
>
> "还有一条顺便提一句：`print` 这种 Python 自己留着的词，也不能拿来当名字。"（提一句即可，不列清单）
>
> "再说一个很多同学会误会的地方——**下划线不是必须的。**"
>
> ```python
> age = 10        # 短名字，直接写
> score = 95      # 不带下划线，也完全可以
> my_score = 95   # 想分清两个词，才加下划线
> ```
>
> "`age`、`score` 这种短名字，直接写就行。**只有**像 `my_score` 这样想让两个词更清楚，才用下划线。别以为名字里必须有下划线。"
>
> 【互动：变量名质检官】（快速抢答，不做笔试）
>
> 屏幕依次出现，学生举手表决"能用 / 不能用"：
> - `age` ✅
> - `score` ✅（不带下划线，也完全可以）
> - `2age` ❌ 数字开头
> - `my_score` ✅
> - `student name` ❌ 中间有空格
> - `print` ❌ Python 自己留着的词
> - `Age` ✅（可以，但注意和 age 不是同一个）

1. 变量 = 给数据起个名字

     name = "小明"

     ✅ age        ❌ 2age（不能数字开头）

     ✅ Age        ⚠️ 和 age 不是同一个名字！
   ➔ 下划线不是必须的：age、score 直接写就行
   ➔ 看到名字，就知道里面装什么

5. ⭐ 今天的问题：为什么不直接改？
   ➔ 你说得对，现在确实可以。
   ➔ 但以后数据会【从外面来】，那时就没法提前写好了。

## 七、课后分层练习与迁移变式库

严格遵循当前知识边界，不使用任何外部标签。

### 题型1：赋值理解

* **题目**：下面这行代码是什么意思？用"放进"这个说法讲一遍。
  ```python
  score = 90
  ```
* **参考答案**：把 `90` 放进名字叫 `score` 的地方。`=` 是"放进去"的动作，不是"等于"。

### 题型2：变量与字符串辨析

* **题目**：下面两行分别输出什么？
  ```python
  name = "小明"
  print(name)
  print("name")
  ```
* **参考答案**：
  - 第一行输出 `小明`（取出 `name` 这个名字里装的值）；
  - 第二行输出 `name`（带引号，是字符串，直接显示这四个字母）。

### 题型3：当前值（本讲重点）

* **题目**：下面代码最后输出什么？为什么？
  ```python
  city = "深圳"
  print(city)
  city = "广州"
  print(city)
  ```
* **参考答案**：依次输出 `深圳` 和 `广州`。第二行 print 之前，`city` 里装的东西被 `"广州"` 换掉了，所以程序读到的是最新的值。

### 题型4：多变量与命名

* **题目**：给"姓名、年龄、爱好"三个数据各起一个变量名，并写出来。
* **参考答案**（示例）：
  ```python
  name = "小明"
  age = 10
  hobby = "编程"
  ```
  要求名字能让人看懂装的是什么。

### 题型5：命名合法性判断

* **题目**：下面哪些名字可以用？不能用的说明原因。
  ```python
  age       2age      my_score     student name     Age
  ```
* **参考答案**：
  - `age` ✅ 可以；
  - `2age` ❌ 不能以数字开头；
  - `my_score` ✅ 可以（字母、下划线）；
  - `student name` ❌ 中间不能有空格；
  - `Age` ✅ 语法上可以，但要注意它和 `age` 是**两个不同的名字**。

### 题型6：找错

* **题目**：下面代码哪里有问题？
  ```python
  age = 10
  print(Age)
  ```
* **参考答案**：`Age` 和 `age` 不是同一个名字（Python 大小写敏感）。程序里只定义过 `age`，没有定义过 `Age`，运行会报错。应改为 `print(age)`。

### 题型7：独立小任务

* **题目**：用三个变量保存你的姓名、年龄、最喜欢的一句话，然后依次输出。
* **参考答案**（示例）：
  ```python
  name = "小明"
  age = 10
  word = "坚持就是胜利"

  print(name)
  print(age)
  print(word)
  ```

### 题型8：变式（进阶）

* **题目**：把下面这段"数据写死"的代码改写成用变量的版本。
  ```python
  print("欢迎")
  print("小明")
  print("小明")
  print("小明")
  ```
* **参考答案**：
  ```python
  name = "小明"

  print("欢迎")
  print(name)
  print(name)
  print(name)
  ```
  追问：如果改成"小红"，你只需要改几个地方？（答：一处）

## 八、教师课堂观察要点

本班为零基础新班，教师在本讲应重点观察（不做筛选，只作教学调整依据）：

1. **是否有孩子提出"为什么不直接改"这个问题** —— 如果有，说明他在真正思考，要给予公开肯定；
2. 孩子读完 `name = "小明"` 后，第一反应说的是"等于"还是"放进去"（判断"先看右边"是否建立）；

6. 是否有孩子写 `2age` 这类数字开头的名字（判断命名规则是否到位）。

> **特别提示**：如果课堂上**没有任何孩子**提出"为什么不直接改"，你不必主动挑起这个话题——按教案正常推进到"重新赋值"时，用第二步的方式自然带出即可。但**如果孩子提了，一定要停下来认真回应**，这是本讲最珍贵的教学时刻。
