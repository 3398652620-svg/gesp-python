# 一、本讲在新班中的位置

## 新班学生的真实起点：两种情况

# 五、本讲必须建立的核心认知

本讲真正需要建立的五个核心认知。

## 核心认知1：`print()` 是"让程序说话"的指令

学生只需建立功能理解：

```python
print("你好")
```

表示：让程序把括号里的内容显示出来。

**不展开**：函数、参数、返回值。函数与参数在后续函数基础节点建立（原规划35），return与返回值在再下一节点建立（原规划36）；实际新班课号待确认，不能合写为同一课首次教学。

教师话术可以是：

> 把 `print` 读成"打印/说出来"，括号就是"要说的内容放进去"。

## 核心认知2：文字必须用成对引号括起来

```python
print("hello")     # 正确
print(hello)       # 程序会报错
```

本讲要正式建立：

> **在 Python 里，文字信息要用引号括起来；程序靠引号知道"这里是一段文字"。**

学生需要认识：

- 单引号 `' '` 和双引号 `" "` 都可以；
- 左右必须配对，不能一个单一个双；

## 核心认知3：数字可以直接写，不需要引号

```python
print(10)      # 数字
print("10")    # 文字
```

这是本讲最重要的认知冲突。

屏幕上都会显示 `10`，但程序内部**不是同一种东西**。

本讲只需埋下种子：

> **对眼睛来说长得一样，对程序来说，一个是数字，一个是文字。**

**不展开**：`int`、`str`、类型转换。这些留到类型转换节点（原规划09，实际新班课号待确认）。

## 核心认知4：多条 print 按顺序执行

本讲正式建立：

```python
print("准备")
print("开始")
print("完成")
```

要求：**先预测，再运行。**

## 核心认知5：代码符号必须是英文半角

这是四年级零基础学生的真实难点，必须单独强调：

- 引号要是英文引号 `"`，不是中文引号 `"`；
- 括号要是英文括号 `()`，不是中文括号 `（）`；
- 逗号、冒号同理。

处理原则：

> 不是让学生背规则，而是建立"**ctrl+空格 切回英文**"的肌肉记忆，并学会从报错里看出"我这行的符号好像和大家不一样"。

# 七、本讲核心问题链

教学设计应围绕以下问题推进，而不是先抛定义。

## Q1
> 看这一行 `print("你好")`，哪部分告诉电脑"要说话"，哪部分告诉它"说什么"？

目标：拆开 print，区分"动作"和"内容"。

## Q2
> 为什么"你好"要放在引号里？直接写 `print(你好)` 会怎样？

目标：制造"引号有作用"的需求。

## Q3
> 引号可以只用一边吗？单引号、双引号，能混着用吗？

目标：建立"成对"意识。

## Q4
> `print(10)` 和 `print("10")`，屏幕上看起来一样，它们真的一样吗？

目标：埋下数字 / 文字的区别种子。

## Q5
> 如果我把三行 print 的顺序调换，结果会怎样？

目标：回收执行顺序，坚持"先预测再运行"。

## Q6
> 为什么有时候复制别人的代码会报错，明明看起来一样？（中文符号陷阱）

目标：把符号准确性作为真实技能建立。

# 十、字符串教到什么深度

本讲只要求：

> **字符串是程序里用来表示文字信息的数据，写在成对引号里面。**

学生能识别以下都是字符串即可：

```python
"深圳"
'Python'
"123"       # 带引号的123，也是字符串
"你好，世界"
```

不要求背定义、不要求使用 `str` 这个类型名。

可以顺口给出中文名："这种写引号里的文字，在 Python 里叫字符串。"

**认知优先于术语。**

# 十一、数字教到什么深度

本讲只需要：

- 知道 `10`、`3.14` 可以直接作为数字写进程序；
- 知道数字不需要引号；
- 暂时不区分 int / float。

```python
print(10)     # 可以
print(3.14)   # 可以
print("10")   # 这是文字，不是数字
```

真正的整数/浮点数分类，随第05、08、09讲自然建立。

# 十二、新班特殊处理：打字与符号

这是本讲与原课研规格**最大的差异点**，因为原规格面向的班级已有基础，而四年级零基础班必须额外处理。

## 必修内容

1. **键盘基本位置**：不必系统教指法，但需告知 `"` 和 `(` 在键盘哪里（英文状态下）；
2. **输入法切换**：强调"写代码时切到英文"，并演示一次中英文标点导致的报错；
3. **新建与保存文件**：本讲是正式第一课，需要正式建立 `File → New File → Save` 的基本流程；
4. **运行与查看结果**：确认每个学生都能独立运行。

## 时间保护原则

> 符号与打字练习必须**融入真实编码任务**，不要单独开一节"打字课"。
> 让学生在写"我的信息卡"时，真实地遇到并解决符号问题。

## 常见错误处理

| 错误 | 处理 |
|---|---|
| 中文引号 `"` | 指出并切回英文，重打一次 |
| 中文括号 `（）` | 同上 |
| 引号只打了一边 | 视觉配对，补齐 |
| 忘了引号 `print(hello)` | 说明程序会把 hello 当别的东西，不是普通文字 |
| 大小写错误 `Print` | 轻量提及"Python 严格区分大小写" |

**注意**：不要展开 `NameError`、`SyntaxError` 术语。只需让学生知道"这行看起来和别人不一样"。

# 十三、本讲程序思维训练点

虽然语法不复杂，但思维训练必须到位。

## 1. 执行顺序继续成为常态
每次多行代码，先预测，再运行。

## 2. 符号有明确意义
引号不是装饰，括号不是装饰——**每个符号都在告诉电脑一件事**。
这与"计算机不会猜你的意思"一脉相承。

## 3. 结果与代码一一对应
学生应能从输出反推：**哪一行代码产生了哪一行结果。**
这是未来 Trace 的种子。

## 4. 从"用"到"懂"
前一阶段是"我会用"，本讲是"我懂它为什么这样写"。

# 十四、本讲题型递进

## 第一层：基础识别
- `print("你好")` 输出什么；
- `print(123)` 输出什么。

## 第二层：同构
- 换内容的输出预测（`print("Python")` / `print("深圳")`）。

## 第三层：辨析
- `10` 与 `"10"` 是否一样；
- 哪一行是数字，哪一行是字符串。

## 第四层：找错
- `print("Hello)` —— 引号不成对；
- `print(Hello)` —— 少了引号；
- 中文括号 / 中文引号。

## 第五层：顺序预测
- 三行 print，预测输出顺序。

## 第六层：变式
- 调换三行顺序，先预测再运行。

## 第七层：小综合（独立任务）
- 独立写一个 3～5 行的「我的信息卡」，包含文字和数字。

本讲可以自然形成：

> **《我的第一张 Python 信息卡》**

本讲的成果是学生用**多行 print 自行搭建的卡片框架**——上边框、标题、信息行、一行不带引号的数字、下边框。

例如：

```python
print("==========")
print("我的信息卡")
print("姓名：小明")
print("爱好：机器人")
print(10)
print("==========")
```

注意：这只是本讲知识自然产生的短小成果。

**不为了"信息卡"提前引入**：变量、f-string、input、颜色、GUI。

**命名规则**：叫「信息卡」即可，不要包装成"项目""大作"。

# 二十四、本讲最终课研结论

新班第一讲不是"从零讲 Python"，而是：

> **把 print 拆开，把字符串和引号立住，把数字和文字分开，并让学生第一次独立完成一次完整的"写—存—跑"。**

四种东西站住以后，第02讲进入变量才有意义：

1. `print()` 是输出指令；
2. 文字要引号，且成对；
3. 数字与文字不是一回事；
4. 代码按顺序执行，符号必须准确。
