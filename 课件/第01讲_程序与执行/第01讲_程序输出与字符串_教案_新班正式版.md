## 一、教学定位与核心目标

### 1. 本讲核心定位
> **把 `print()` 从"一整行指令"正式拆开，建立字符串与引号概念，第一次区分"数字"和"看起来像数字的文字"，并完成从"跟着跑"到"独立写出来"的跨越。**

本讲是正式班的第一节课，**必须自成一体**：不假设学生上过体验课。上过体验课的学生当作温故+加深，首次接触的学生能完整跟上。

> **独立性原则**：体验课（若有）只作为"锦上添花"的熟悉感，不作为承重墙。任何一句课堂话术、任何一个课件页面，都不允许依赖体验课的具体内容。

> **自然显性成果定位**：依据课次地图，本讲自然形成《我的第一张 Python 信息卡》（`my_card_01.py`），不强行包装为项目。

### 2. 核心素养与教学目标

1. **正式认识输出工具**：理解 `print()` 是让程序把内容显示出来的指令，能区分"动作"（print）与"内容"（括号里的东西）；
2. **字符串与引号**：理解文字信息必须用**成对引号**括起来，单引号、双引号均可，建立"引号告诉程序这里是文字"的认知；
3. **数字与文字辨析**：认识 `print(10)`（数字）与 `print("10")`（文字）在屏幕上看起来一样，但程序内部不是同一种东西，为后续类型转换埋种子；
4. **符号准确性**：建立"代码符号必须英文半角"的实操意识，能识别中文引号、中文括号、引号不成对等常见错误；
5. **执行顺序常态化**：多行代码坚持"先预测、再运行"，建立执行流认知；
6. **完整操作闭环**：第一次独立完成"新建文件 → 写代码 → 保存 → 运行 → 看结果"，形成正式课堂的操作习惯。

## 二、教学重难点与认知边界

### 1. 教学重点
- `print()` 的结构（动作 + 括号 + 内容）；
- 字符串概念与引号成对；
- 数字与字符串的初步区别；
- 多行代码顺序执行的预测与验证。

### 2. 教学难点
- 四年级学生对"引号为什么要成对"缺乏直觉；
- 中英文标点混用（最常见、最影响信心的问题）；
- 理解"屏幕上一样"不等于"程序里一样"；
- 第一次独立新建与保存文件的完整操作。

### 3. 严格禁止超纲禁区（守卫底线）
- ❌ 严禁正式教授 `int` / `float` / `str` 术语背诵；
- ❌ 严禁把多内容逗号输出 `print("姓名：", 10)` 作为核心要求；
- ❌ 严禁提前引入变量、赋值、`input()`、类型转换、`type()`；
- ❌ 严禁展开 `NameError`、`SyntaxError` 术语（只说"这行看起来和大家不一样"）；
- ❌ 严禁引入参数、函数、转义字符、`sep`、`end`；
- ❌ 严禁重讲计算机硬件百科与 Python 发展史（不在本讲范围内）；

## 四、课堂教师话术与分镜教学指引

### 1. 导入话术（第01~02幕）

> "同学们，欢迎来到我们的第一堂 Python 编程课！
>
> 先看看周围——**有的同学上次来过，已经让电脑说出过自己的名字；有的同学今天是第一次来**。都没关系，因为今天对所有人来说，都是新的开始。
>
> 看屏幕上的这一行小字：
>
> ```
> print("你好")
> ```
>
> 不管你有没有见过它，今天我们要做一件**从来没有做过的事**——把它**彻底拆开**，看清里面每一块零件是干什么的。
>
> 学完之后，你不光会改别人的代码，还能**从一张白纸开始，自己写出来**。而且今天你们每个人都会亲手新建一个属于自己的文件。"

### 2. 拆解 print 话术（第03~04幕）

> "我们来看这行代码：`print("你好")`。它其实分成两半——
>
> 前面这个 `print`，你可以把它读成**'说出来'**，它是一个动作，告诉电脑：**我要说话了**。
>
> 后面这一对括号，里面装着**要说的内容**。括号就像一个嘴巴，你把想说的话塞进去。
>
> 所以这一整行的意思就是：**说出来——你好。**
>
> 现在老师考考你：如果括号里换成 `"我是小明"`，屏幕上会显示什么？**先别急着说，自己想三秒钟。**"

（点名回答后运行验证）

> "看到没有？你**猜对了**！说明你已经看懂了这行代码的结构。"

### 3. 字符串与引号话术（第05~07幕）

> "现在有个问题：为什么'你好'要加引号？我们试试不加会怎么样——"
>
> （演示 `print(你好)`，报错）
>
> "咦，报错了！为什么加引号就对，不加就错？
>
> 因为电脑不会猜。你写 `你好`，电脑会以为这是**某个东西的名字**，它翻遍整个程序也没找到'你好'是什么，就急了、报错了。
>
> 但如果你加上引号 `"你好"`，就等于告诉电脑：**'这里面是一段文字，直接把它显示出来就行'。**
>
> 所以记住：**在 Python 里，文字要穿一件'引号外套'。**
>
> 而且这件外套必须**成对穿**——左边一个，右边一个。就像穿鞋子，一只穿左边一只穿右边，当然不行。单引号 `'` 和双引号 `"` 都可以，但**前后必须一样**。"

### 4. 数字与文字辨析话术（第08~09幕）

> "接下来是最有意思的地方。看这两行：
>
> ```python
> print(10)
> print("10")
> ```
>
> 请你们仔细看屏幕——上面显示的是不是都是 `10`？
>
> 看起来一模一样，对吧？那老师问你们：**它们真的一样吗？**
>
> （让学生猜，制造悬念）
>
> "答案是：**对眼睛来说一样，对电脑来说不一样。**
>
> 上面那个是**数字** 10，可以拿去算数；下面那个是**文字** '10'，只是一串长得像数字的字符。
>
> 你可以这样想：一个是**真正的 10 块钱**，一个是**10 块钱的玩具纸币**。看起来像，但一个能花，一个不能。
>
> 它们到底哪里不一样？这个秘密，我们后面讲运算的时候会揭开。**今天先记住一件事：它们不一样。**"

### 5. 符号陷阱话术（第10~11幕）

> "现在老师要给大家演示一个'最坑人'的错误。看好了——"
>
> （现场切到中文输入法，打出中文引号，运行）
>
> "咦？报错了！你们看看这两行，是不是**长得几乎一模一样**？"
>
> "这就是编程里最大的陷阱：**中文标点和英文标点长得像，但电脑只认英文。**"
>
> "你可以这样理解：电脑只听得懂'英文频道'。你要跟它说话，就得先**调到它听得懂的那个频道**。"
>
> "以后写代码前，先做一件事：**按 Shift，把输入法切到英文。** 就像打电话要先拨对号码一样，写代码要先切对输入法。"
>
> （可让学生自己打一次中文引号，亲手体会报错）

### 6. 顺序预测话术（第12~13幕）

> "现在三行代码，先别运行，谁能预测屏幕上的顺序？
>
> ```python
> print("准备")
> print("开始")
> print("完成")
> ```
>
> （点名回答后运行）"
>
> "如果我们把这段顺序改成——"
>
> ```python
> print("完成")
> print("准备")
> print("开始")
> ```
>
> "电脑会不会觉得'这个顺序不合理'，自己帮我们调回来？**不会！** 电脑只会老老实实**按你写的顺序执行**。这又一次证明了：**电脑不会猜你的意思。**"

### 7. 独立实战引导（第14~15幕）

> "现在我们每个人都要有自己的文件了。跟着老师做：
>
> 第一步：`File → New File`，新建一个文件。
> 第二步：`File → Save`，保存，文件名就叫 `my_card_01`。
> 第三步：照着屏幕写你的信息卡。
> 第四步：点运行，看看你自己的程序说出的话！
>
> 注意——**这次不是一句话，而是一张完整的卡片**。我们要用**很多行 print，搭出一个完整的卡片框架**：最上面一条边框、中间是标题和信息、还有一行**不带引号的数字**、最后一条边框收尾。写完之后，一张漂亮的卡片就立起来了！
>
> 记住：**先在心里猜一遍结果，再运行。**"

**参考代码**：

```python
print("==========")
print("我的信息卡")
print("姓名：小明")
print("爱好：机器人")
print(10)
print("==========")
```

> 教师提示：第 5 行 `print(10)` 不带引号，是本讲的"埋点"。学生敲完运行后，可追问："这一行和上面几行有什么不一样？为什么它不用引号？"引出对"数字 vs 文字"的再次确认。

### 8. 收束话术（第16幕）

> "今天我们完成了一件大事：**从'跟着跑'变成了'自己写'。**
>
> 现在老师问三个问题——
> 1. `print()` 是做什么的？
> 2. 文字为什么要加引号？
> 3. `10` 和 `"10"` 一样吗？
>
> （学生回答后）"
>
> "最后一件事：如果'小明'这个名字，我们要用 10 次，难道每次都重新写一遍吗？程序能不能把数据**记住**？
>
> 下节课，我们学 **变量**。"

## 七、课后分层练习与迁移变式库

严格遵循当前知识边界，不使用任何外部标签，供课后练习与课堂小测使用。

### 题型1：基础输出预测
* **题目**：写出下面代码的输出结果。
  ```python
  print("你好")
  print(123)
  ```
* **参考答案**：
  ```
  你好
  123
  ```

### 题型2：字符串与引号辨析
* **题目**：下面哪几行能正常运行？为什么？
  ```python
  print("Python")
  print(Python)
  print('深圳')
  print("深圳')
  ```
* **参考答案**：
  - `print("Python")` ✅ 正确，文字用成对引号；
  - `print(Python)` ❌ 没有引号，程序会把 Python 当别的东西；
  - `print('深圳')` ✅ 正确，单引号也可以；
  - `print("深圳')` ❌ 引号不成对（左双引号、右单引号）。

### 题型3：数字与文字辨析
* **题目**：下面两行的输出在屏幕上看起来一样吗？它们是同一种数据吗？
  ```python
  print(10)
  print("10")
  ```
* **参考答案**：屏幕上看起来都是 `10`，`print(10)` 输出的是**数字**，`print("10")` 输出的是**文字**，二者不是同一种数据。

### 题型4：顺序预测与变式
* **题目**：先预测输出顺序，再说明如果交换前两行会怎样。
  ```python
  print("第一")
  print("第二")
  print("第三")
  ```
* **参考答案**：按顺序输出「第一 / 第二 / 第三」；交换前两行后输出变为「第二 / 第一 / 第三」，因为程序严格按照代码书写顺序执行。

### 题型5：找错（符号类）
* **题目**：下面这段代码有一个问题，请找出来并改正。
  ```python
  print（"我是小学生"）
  ```
* **参考答案**：括号使用了**中文括号** `（）`，应改为**英文括号** `()`，即 `print("我是小学生")`。写代码时需将输入法切换到英文。

### 题型6：独立小任务
* **题目**：独立写一段程序，让屏幕依次输出：
  - 第一行：你的姓名
  - 第二行：你的年龄（用数字，不加引号）
  - 第三行：你最喜欢的一句话（用引号）
* **参考答案**（示例）：
  ```python
  print("小明")
  print(10)
  print("坚持就是胜利")
  ```
