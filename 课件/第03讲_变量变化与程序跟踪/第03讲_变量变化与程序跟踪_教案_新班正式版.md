## 一、教学定位与核心目标

### 1. 本讲定位

第02讲让学生知道「变量可以改」。本讲第一次让学生真正看到：

> **程序是在时间中运行的。**

同一个变量，现在是 5，下一行以后可能是 7，再下一行以后可能是 10。所以读代码不能只问「写了什么」，必须问：

> **执行到这一行时，变量现在是多少？**

### 2. 核心目标（学生学完能做到）

1. 解释 `x = x + 1` 的执行过程（右边先取当前值 → 算 → 放回左边）；
2. 会逐行跟踪 3～5 次连续更新；
3. 能用简单状态表（Trace Table）跟踪两个变量；
4. 理解 `b = a` 是把「当时」a 的值交给 b，之后 a 改变不影响 b；
5. 能判断多个 `print()` 分别输出的是哪个时刻的值。

### 3. 与前两讲的衔接

| 讲次 | 学生已建立 |
|---|---|
| 第01讲 | 程序会执行、`print()`、字符串与数字 |
| 第02讲 | 变量、`=` 是「动作」、当前值、命名规则 |
| **第03讲（本讲）** | **变量怎样一步一步变化** |

**关键**：第02讲收束幕已经埋下悬念 `age = age + 1`，并明确写了「只留悬念，不解释、不练习」。本讲**开场第一件事就是回收它**。

## 二、教学重难点与认知边界

### 1. 教学重点
- 赋值语句「先算右边，再更新左边」的执行顺序；
- 逐行跟踪（Trace）的思维方式；
- 状态表作为思维支架的使用。

### 2. 教学难点
- **打破数学等号思维** —— `x = x + 1` 在数学里不成立，学生需要用「动作」重新理解（本讲最大难点）；
- **旧值 vs 当前值的区分** —— 学生容易把「出现过的值」都当成当前值；
- **`b = a` 的时刻性** —— 学生容易以为变量之间永久绑定。

### 3. 严格禁止超纲禁区（守卫底线）

- ❌ 严禁把 `x = x + 1` 教成口诀「就是加 1」而不解释过程；
- ❌ 严禁正式教授 `+=` / `-=` / `*=` / `/=`；
- ❌ 严禁引入 `input()`、类型转换；
- ❌ 严禁引入 if / for / while / 函数 / 列表；
- ❌ 严禁讲复杂变量交换算法；
- ❌ 严禁讲内存地址、对象引用模型；
- ❌ 严禁用复杂算术（`//` `%` `**` 大数运算）掩盖状态学习；
- ❌ 严禁把 Trace Table 做成纯机械填表题；
- ❌ 严禁用大量娱乐包装挤掉状态推演时间。

> **本讲的算术只是为了让「状态更新」发生，不是为了教运算体系。**

## 四、课堂教师话术与分镜教学指引

### 1. 悬念回收话术（第01~03幕）★ 开场就要抓人

> "同学们，上节课最后，老师在屏幕上留下了一行代码，你们还记得吗？"
>
> （出示）
>
> ```python
> age = age + 1
> ```
>
> "上节课我说：**先记住它，以后会讲。今天，就是那个时候。**"

> （停一下，问）
>
> "先别管程序。老师问你们一个数学问题——"
>
> "`age` 等于 `age + 1`。在数学课上，这句话成立吗？"
>
> （孩子会答：不成立！/ 错的！）
>
> "**对，说得完全正确。**在数学里，这句话是错的。
>
> 可是——它在 Python 里，**能正常运行**。"

> "而且上节课我们还说过，这个 `=` 不是'等于'，它是一个**动作**。
>
> 今天，我们就用这个'动作'，来解开这个看起来矛盾的式子。"

**【要点】** 不要急着给答案。让孩子先感到"矛盾"，再给解释。矛盾感越强，后面的解释越有记忆点。

### 2. 单变量更新机制话术（第04~06幕）★ 本讲最关键

> "我们先来一步一步看，程序执行这行的时候，到底发生了什么。"

```python
x = 10
x = x + 1
```

> "程序是从上往下执行的，对吧？那先看第一行——
>
> `x = 10`：把 10 放进名字 `x` 里。现在 `x` 里面是几？"
>
> （齐答：10）
>
> "好。现在看第二行。这行有个特别的地方：**`x` 出现了两次**，一左一右。
>
> 那程序先处理哪一边？"
>
> （多数孩子会犹豫）
>
> "记住一句话，这句话今天你要带回家——"
>
> **【板书 · 全班齐读两遍】**
>
> > **先算右边，再更新左边。**
>
> "好，那我们按这个规则来："
>
> "**第一步，先算右边。** 右边的 `x` 现在是多少？"
>
> （答：10）
>
> "**第二步，右边算出来。** 10 加 1，等于几？"
>
> （答：11）
>
> "**第三步，把算出来的 11，放回左边的 `x` 里。**"
>
> "现在，`x` 里面变成了几？"
>
> （齐答：11）

> "看，问题解决了吧？**数学里不成立，是因为数学里的 `=` 是'两边一样'。
> 但在程序里，`=` 是个动作：先把右边算好，再把结果放回左边。**
>
> 所以这行代码，不是'证明 x 等于 x+1'，而是**'让 x 变成 x+1'**。"

**【互动 · 第06幕】**
> "来，我考考你们。这一次右边加的是 2——"

```python
x = 10
x = x + 2
```

> "谁来一步一步说给全班听？第一步干什么？"

（期望回答："第一步看右边，x 现在是 10；第二步算 10 + 2 等于 12；第三步把 12 放回 x。所以 x 现在是 12。"）

**【易错提示】** 如果有孩子说"x 先等于 10，又等于 12，两个都算"——立刻回："**记住，程序只记得'现在'。10 已经过去了，现在 x 里面只有 12。**"

### 3. 连续更新话术（第07~09幕）

> "那如果不止一次呢？我们来看这一小段。"

```python
x = 5
x = x + 2
x = x + 3
```

> "**不要猜答案。** 我们今天学一个更可靠的办法——**一行一行地跟**。"

> "第一行 `x = 5`。执行完，x 现在是几？"（5）
>
> "第二行 `x = x + 2`。先算右边：现在的 x 是 5，5 加 2 是 7。放回左边。**执行完后 x 是几？**"（7）
>
> "第三行 `x = x + 3`。注意！右边取的是**现在**的 x，不是最开始的 x。现在的 x 是 7，7 加 3 是 10。放回去。**现在是几？**"（10）
>
> "所以这个 x，它的变化过程是——"（板书）
>
> ```text
> 5  →  7  →  10
> ```

> "它不是一下子跳到 10 的，是**一步一步变过去的**。
>
> 这就是今天最重要的感觉：**程序是在时间里运行的。**"

**【互动 · 第08幕】**
> "那如果在中间插一句 `print` 呢？"

```python
x = 5
print(x)
x = x + 2
print(x)
```

> "第一次打印出来是几？第二次呢？"
>
> （答：5 和 7）
>
> "为什么两次不一样？"
>
> （期望："因为中间 x 变了"）
>
> "对。**`print` 打印的，是'执行到那一行时'的当前值。** 它不会自己去更新。"

### 4. Trace 方法话术（第10~11幕）★ 工具引入

> "好，现在问题来了。刚才只有 3 行，我们还能跟。要是 6 行、8 行呢？万一有两个变量呢？
>
> 光靠脑子跟，很容易跟丢。
>
> 所以今天老师教你们一个工具——**状态表**。"

**【板书 Trace Table 表头，强调三个字】**

> | **执行这一行后** | x |
> |---|---:|
> | `x = 5` | 5 |
> | `x = x + 2` | 7 |
> | `x = x + 3` | 10 |

> "注意表头。它不是写'这一行有几个'，而是写——"
>
> **"执行这一行**之后**，变量变成了几"。**

> "为什么要这样写？因为变量是**会变的**。我们关心的不是它曾经是什么，是**这一刻它是什么**。"

**【强调用途】**
> "但老师要说清楚：**这个表不是目的，是拐杖。**
>
> 到最后，你脑子里不用画表也能跟得上。现在用表，是因为它帮你**不掉线**。"

### 5. 两变量话术（第12~13幕）

> "现在难度升级。看这一段——"

```python
a = 3
b = 5
a = a + 2
b = b + 1
```

> "这次有**两个**变量。记住：**一个变量一列，不要混在一起。**"

> | **执行这一行后** | a | b |
> |---|---:|---:|
> | `a = 3` | 3 | — |
> | `b = 5` | 3 | 5 |
> | `a = a + 2` | 5 | 5 |
> | `b = b + 1` | 5 | 6 |

> "第三行改的是 a，b 动了吗？"
>
> （答：没动）
>
> "对。**每一行只改它左边的那个变量，别的变量不动。**
>
> 所以我们要**分开跟**，a 有 a 的当前值，b 有 b 的当前值。"

**【互动 · 第13幕】** 让孩子说出每一步两列各是多少。

### 6. `b = a` 关键变式话术（第14幕）★ 认知陷阱

> "最后，老师要出一道**特别容易错**的题。我保证有人会掉进去。"

```python
a = 3
b = a
a = 5
print(b)
```

> "先猜猜，`print(b)` 会打印几？"
>
> （大量孩子会答 5）
>
> "**答案是 3。**"
>
> （孩子会惊讶）
>
> "为什么？我们回到第二行：`b = a`。
>
> 这一行执行的时候，a 里面是几？"
>
> （答：3）
>
> "所以 **b 拿到的是 3**。注意——b 拿到的是**那个时刻的值**，不是'跟着 a 走'。
>
> 然后第三行改动的是 **a**，它把 a 变成了 5。可是 b 里面还是 3。
>
> **a 变了，b 不会自动跟着变。它们不是绑在一起的。**"

> （板书）
>
> ```text
> a = 3   →  a:3
> b = a   →  a:3  b:3     ← b 拿到的是"当时"的 3
> a = 5   →  a:5  b:3     ← a 变了，b 没动
> ```

**【一句话总结】** "**每一次赋值，都发生在'那一刻'，拿的是'那一刻'的值。**"

### 7. 独立实战话术（第15幕）

> "现在轮到你们了。这段程序，自己推，不要运行。"

```python
x = 1
x = x + 4
x = x + 2
print(x)
```

> "推完的同学，把每一步的 x 写在旁边。写完了再运行验证。"

（巡视，重点看有没有孩子跳过中间步骤直接猜）

**答案**：1 → 5 → 7，输出 `7`。

### 8. 收束与预告话术（第16幕）

> "今天我们学了什么？三个问题——"
>
> 1. `x = x + 1` 为什么不违反数学？（因为 `=` 是动作：先算右边，再更新左边）
> 2. 程序执行一行以后，旧的还算是当前值吗？（不算，只有最新结果）
> 3. 如果不止一个变量，怎么办？（一个变量一列，分开跟）

> "最后，老师再留一个悬念——"
>
> "我们今天用到的，只有 `+1`、`+2`、`+3`。"
>
> "那如果我想要——**分数翻倍**呢？**只取最后一位数字**呢？
>
> 右边那个位置，到底能写多少种算法？"
>
> "下节课，我们就把右边**正式打开**。"

### 家长反馈话术（350 字以内）

> 各位家长好👋
> 本次课程主题是《变量变化与程序跟踪》。
>
> ✅课堂学习要点：
> 1. 认知知识：本节核心是理解 `x = x + 1` 这种写法。孩子在数学里学的「=」是两边相等，但在 Python 里「=」是一个动作——先把右边算出来，再放回左边。跟着这个规则，孩子学会了逐行跟踪变量的变化，比如 `x = 5` → `x = x + 2` → `x = x + 3`，x 是一步一步从 5 变到 7 再变到 10 的。
> 2. 重点提醒：本节有一个容易错的点——`a = 3`、`b = a`、`a = 5` 之后，`print(b)` 输出的是 3 不是 5。孩子要理解 b 拿到的是「当时」a 的值，之后 a 再变，b 不会跟着变。

## 七、课后分层练习与迁移变式库

### 第一层：确认当前值（复习第02讲）
```python
x = 5
x = 8
print(x)      # 8
```

### 第二层：单次基于旧值更新 ★ 本讲起点
```python
x = 5
x = x + 1
print(x)      # 6
```

### 第三层：连续更新
```python
x = 2
x = x + 3
x = x + 4
print(x)      # 9
```

### 第四层：插入输出
```python
x = 2
print(x)      # 2
x = x + 3
print(x)      # 5
```

### 第五层：两变量分别更新
```python
a = 2
b = 5
a = a + 1     # a → 3
b = b + 2     # b → 7
print(a, b)   # 3 7
```

### 第六层：`b = a` 变式 ★ 陷阱题
```python
a = 3
b = a
a = 5
print(b)      # 3（不是5！）
```

### 第七层：减法更新
```python
hp = 100
hp = hp - 30
print(hp)     # 70
```

### 第八层：小综合 Trace（4~6 行）
```python
x = 10
y = x
x = x + 5
y = y - 2
print(x)      # 15
print(y)      # 8
```

### 第九层：找错题
```python
x = 3
x = x + 1
```
> 问：有同学说「x 现在同时是 3 和 4」。他哪里想错了？
> 答：程序只保留**最新**的值，x 现在只有 4。

## 八、教师课堂观察要点

### 需要介入的信号
- 孩子跳过中间步骤直接猜最终答案 → 要求他「一行一行说现在是多少」；
- 孩子说 `b = a` 后 b 也跟着变成 5 → 回到"那一行执行时，a 是几"；
- 孩子把 `x = x + 1` 读成"x 等于 x 加 1" → 立刻纠正读法："让 x 变成 x 加 1"。

### 不必介入的情况
- 孩子在纸上画了状态表 → 很好，这正是本讲要的支架，**不要打断**；
- 孩子推理慢一点但步骤是对的 → 给时间，不要抢答；
- **如果课堂上没有任何孩子对 `x = x + 1` 感到意外** → 可以主动问"数学里这样写，老师会不会打叉？"来制造冲突，但**不必强行激发**。

### 特别提醒
> 本讲是第一阶段**思维负荷最高**的一讲。宁可少讲一个变式，也要保证「先算右边，再更新左边」这条规则**每个孩子都能背出来并会用**。
