🏷️ 变量 (Variable)
能不能先给数据起一个名字？
让程序把数据记住，之后直接呼唤名字使用它！
核心概念

变量与赋值语句：name = "小明" 🔍

name = "小明"
1. name 变量名
程序给数据起的名字（专属标签）
2. = 赋值符号
不是数学等号！表示“把右边的值交给左边保存”
3. "小明" 当前值
当前被保存在变量里的具体数据
核心思维

赋值方向：先看右边，再赋给左边 ⬅️

score = 90
❓ 这行代码最准确的理解是什么？
🎯 赋值黄金口诀
先看右边是什么数据
➔ 再把结果赋给左边的变量名保存！
程序从此记住了它的当前值！
核心认知冲突

print(name) 与 print("name") 一样吗？🤔

📌 变量定义前提： name = "小明"
🧠 变量 name 当前记住的值是 "小明"
❓ 写法一：print(name)
print(name)
➔ 屏幕输出：小明
没有引号，Python 会去寻找变量 name 当前保存的值！
❓ 写法二：print("name")
print("name")
➔ 屏幕输出：name
带了双引号，Python 会把它当作普通字符串文字原样输出！
🌟 核心认知：在已定义变量的前提下，不带引号是取变量当前值，带了引号则是输出字符串！

规则指南

变量命名规则：本阶段四大原则 📜

✅ 1. 允许使用的字符：
本阶段我们统一使用英文字母、数字和下划线 _ 来命名变量。
例如：age, score_1, _count
🚫 2. 严禁以数字开头：
变量名绝对不能以数字开头！
2score ❌ ➔ 应该写成 score2 ✅
🚫 3. 严禁包含空格：
变量名是一个整体，中间不能有空格！
my age ❌ ➔ 应该写成 my_age ✅
🔠 4. Python 严格区分大小写：
age = 12 与 Age = 15 是两个完全独立的变量！

编程素养

关键字保护与“见名知意”好习惯 💡

⛔ 关键字不能作变量名：
for = 10
SyntaxError (语法错误)
Python 中的 if, for, while 是核心语法保留词，不能作为变量名！
🌟 见名知意原则：
• a = "小明"（别人读不懂 a 是什么）
• name = "小明"（一目了然知道是姓名！）
💡 常量彩蛋：程序员常用全大写（如 PI = 3.14）表示约定不改的固定值。

程序状态

重新赋值：变量记住的是“当前最新的值”！🔄

🧠 变量即状态
变量不是一成不变的！每当程序执行一次新的赋值语句，变量就会丢掉旧值，记住全新的当前值！
🔍 思考：当城市改变时
如果先写 city = "深圳"，后来搬家了又写 city = "广州"，那么程序现在记住的到底是谁？让我们通过下一幕互动亲自推演！
