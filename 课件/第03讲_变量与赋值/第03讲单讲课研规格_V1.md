# 一、本讲在整套课程中的位置

第02讲学生已经会：

```python
print("小明")

```

也已经知道：
- 程序可以输出文字和数字；
- 字符串需要引号；
- 多行代码按顺序执行；
- `10` 与 `"10"` 在程序中不是完全相同的数据形式。

但这些数据仍然都是直接写死在代码里的。

第03讲第一次解决：

> **如果一个数据后面还要继续使用，程序怎么把它记住？**

于是变量出现。

这不是“Python语法表里的下一个知识点”，而是整套课程真正进入：

> **程序状态**

的第一步。

# 二、本讲核心定位

> **让学生理解：变量是程序给数据起的名字，用来保存当前需要记住的值；赋值是在更新程序当前保存的状态。**

本讲重点不是背“变量像盒子”。

可以使用盒子、标签等比喻帮助理解，但最终必须走向：

> **变量名对应的是程序当前保存的数据。**

---

# 三、本讲为什么现在教

第02讲的固定输出已经制造了天然局限：

```python
print("小明")
print("小明")
print("小明")
```

如果同一个数据反复出现，每次都重新写：
- 麻烦；
- 容易改漏；
- 无法表达“这个数据以后还会变化”。

因此自然提出：

> 有没有办法先把“小明”记住，后面需要时直接用它的名字？

变量由真实需求产生，而不是直接给定义。

# 五、本讲必须建立的核心认知

## 1. 变量是数据的“名字”

```python
name = "小明"
```

学生需要理解：

> 程序把 `"小明"` 这个数据交给 `name` 这个名字保存。

之后：

```python
print(name)
```

程序会使用变量当前保存的值。

关键不是“盒子长什么样”，而是：

> **变量名让程序可以重复引用同一个数据。**

## 2. `=` 在程序里表示赋值，不是数学等号

```python
age = 12
```

这里不是在证明 age 和 12 永远相等，而是：

> **把右边的值交给左边的变量名保存。**

本讲应建立一个稳定阅读方向：

> **先看右边是什么，再把结果交给左边。**

这会直接服务第04讲：

```python
x = x + 1
```

## 3. 变量可以保存不同形式的数据

```python
name = "小明"
age = 12
height = 1.52
```

不要求本讲完整背 `str/int/float`，但要延续第02讲：

> **不同形式的数据都可以被变量保存。**

## 4. 变量名必须遵守规则

一级必要内容：
- 可以使用字母、数字、下划线；
- 不能以数字开头；
- 不能随意带空格；
- Python 大小写敏感；
- 关键字不能作为普通变量名。

例如：

```python
age = 12
age2 = 13
student_name = "Tom"
```

合法。

而：

```python
2age = 12
student name = "Tom"
for = 10
```

不合法。

## 5. 好的变量名应该让人看得懂

```python
a = "小明"
b = 12
```

虽然可能合法，但：

```python
name = "小明"
age = 12
```

更容易理解。

目标不是专业命名规范，而是建立：

> **变量名最好能表达它保存的是什么。**

# 八、本讲正式教学内容

必须正式教授：

1. 变量与赋值
```python
name = "小明"
age = 12
```

2. 使用变量输出
```python
print(name)
print(age)
```

3. 不同变量保存不同数据。

4. 简单重新赋值
```python
name = "小明"
name = "小红"
print(name)
```

只建立：后一次赋值会更新当前值。

5. 基础变量命名规则。

6. Python 大小写敏感：
```python
age = 12
Age = 15
```
视为不同名字。

7. 关键字不能作为普通变量名。可用 `if/for/while` 举例，但不要求背完整关键字表。

# 九、标识符与关键字教到什么深度

“标识符”这个术语可以出现，但不能让术语压过认知。

学生最终要会判断：

| 名称 | 是否可作为基础变量名 |
|---|---|
| `age` | 可以 |
| `age2` | 可以 |
| `student_name` | 可以 |
| `_score` | 可以认识为合法 |
| `2age` | 不可以 |
| `student name` | 不可以 |
| `for` | 不可以 |
| `my-score` | 不可以 |

本阶段不展开：
- Unicode 标识符；
- 双下划线特殊名称；
- PEP 8完整规范。

# 十八、本讲常见错误及处理原则

## 错误1：把变量名加引号
```python
name = "小明"
print("name")
```
处理：明确变量名与字符串边界。

## 错误2：变量名数字开头
```python
2age = 12
```
处理：回到命名规则，不展开词法分析。

## 错误3：用关键字作变量名
```python
for = 10
```
处理：说明Python把某些词留给语法使用。

## 错误4：认为大小写相同
```python
age = 12
print(Age)
```
处理：强调大小写敏感。

## 错误5：把 `=` 当“等于”
教师应进一步说：
> 在Python赋值语句里，更准确是“把12赋给age”。

## 错误6：认为重新赋值后旧值仍是当前值
通过简单运行观察纠正，复杂状态追踪留给第04讲。
