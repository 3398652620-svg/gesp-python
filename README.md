# GESP Python 一级与基础拓展（38讲课研与高交互课件）

本仓库是本课程项目的**唯一长期正本（Single Source of Truth）**。聊天记录、临时文件、旧补丁与其他端同步副本均不高于本仓库中的当前有效文件。

## 一、权威层级

课程研发与验收统一遵循以下顺序：

1. `GESP_Python_一级与基础拓展_38讲课程总纲_V3.2.md`
2. `七阶段知识依赖设计_V1.1.md`
3. `38讲课程课次地图_V1.1.md`
4. 各讲单讲课研规格
5. 各讲 HTML 课件与教学教案

若后续任何一次课研无法读取必要上位文件，不得自行重设课程逻辑，应先停止并说明缺失资料。

## 二、课程定位

- 01～32：GESP Python 一级核心课程
- 33～38：Python 基础拓展（列表、函数、二维列表等）
- 单节课 90 分钟，按约 80 分钟有效教学容量设计
- 课程主线：**知识决定主线，问题驱动思考，任务承载练习，项目负责整合**
- 对外简化表达：**知识驱动，问题承载，项目调味**

## 三、当前有效的 GESP 校准

- 第31讲：GESP 一级综合限时实战 / 全真模拟前训练，仍属于正常 90 分钟课次
- 阶段测试 T6：独立 120 分钟 GESP Python 一级全真模拟，不占用 38 讲课次
- 第32讲：基于 T6 真实结果进行复盘、错误归因与能力收束
- 计算机基础常识采用 01～28 轻量分布式覆盖 + 第29讲集中复习

原 `GESP一级官方核查补丁_V1.md` 的有效内容已经合并进当前总纲 V3.2、七阶段 V1.1、课次地图 V1.1。旧补丁仅保留历史追溯价值，不再作为独立执行规范。

## 四、逐讲交付结构

每一讲原则上独立成套，包含：

1. **单讲课研规格（.md）**：锁定教学定位、知识边界、类题递进与能力出口
2. **高交互单文件 HTML 课件（.html）**：单页单焦点、程序状态可视化、交互与即时反馈
3. **80分钟教学教案（.md）**：教师分镜、追问话术、易错点与家校反馈口径

当前已形成 01～04 讲三件套目录结构，后续课次继续沿用，不再另起新的目录体系。
