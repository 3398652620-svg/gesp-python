# GESP Python 一级与基础拓展（38讲课研与高交互课件）

本项目是面向 **GESP Python 一级考试与少儿编程基础拓展（共38讲）** 的全套金牌课程研发体系。

## 一、 上位依据与规范文件
- `GESP_Python_一级与基础拓展_38讲课程总纲_V3.2.md`：总纲体系与教学理念
- `七阶段知识依赖设计_V1.1.md`：七阶段递进与硬性熔断守卫表
- `38讲课程课次地图_V1.1.md`：38讲全套课次定位、核心知识、认知冲突与能力出口
- `课件/GESP一级官方核查补丁_V1.md`：考纲真题核对与补丁规范

## 二、 教学课件与教案结构（逐讲交付）
每讲均独立成套，包含：
1. **单讲课研规格（.md）**：锁定教学定位、知识边界、类题递进与能力出口；
2. **高交互单文件 HTML 课件（.html）**：单页单焦点、拟真终端输出、Step-Reveal 渐进式展示、GSAP 动效与即时反馈；
3. **80分钟教学教案（.md）**：教师分镜引导、追问话术、常见易错点与家校反馈口径。
